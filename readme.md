## Old feedback on design

I do think on a quick scan right now the jumbotron photo + icons do make it actually seem like a car website or something to do with cars, which may be more on-the-nose than you’re looking for. In a squint test I don’t know if I’d realize this site was about web performance

I like the graphic of the racing stripes, but because of its proportions it kind of makes me think of a flag? Maybe it’s just because I see the French flag all the time (and this is like a reversed French flag). I think you could keep the “racing stripes” idea but change the proportions slightly and it wouldn’t look so flag-y


I think an image that evokes “fast” and is a long exposure of lights of some kind can evoke the car theme without making the squint/scan test read so much as literally “car”
